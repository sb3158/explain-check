# check: 큰 변경 직후

핵심 계산·판정 로직이나 모듈 구성을 바꾼 직후에 따른다(AGENTS.md 규칙). 사용자가 직접 불러도 된다.

1. 변경을 8줄 안에 설명한다: 무엇을, 왜 바꿨는지, 새로 생긴 위험, 사용자가 직접 확인할 명령.
2. 프로젝트 루트 EXPLAIN.md "설계"의 결과 지표를 기준선·변경 전·변경 후로 비교한 표를 보여준다.
3. 1~2번은 결과와 상관없이 항상 사용자에게 보여준다. 지표가 나아졌고 설계와 맞으면 보여준 뒤 유지하고 작업을 이어간다. 지표가 나빠졌거나 설계와 달라졌으면 유지할지 되돌릴지 묻는다 **(결정)**.
4. "결정"에 남길 한 줄을 만든다: 계기, AI 제안 중 수용·수정·버린 것, 근거가 된 지표나 실행 결과. 설계가 달라졌거나 모듈이 생기거나 없어지거나 역할이 바뀌었으면 "설계"에 고칠 내용도 만든다.
5. plan을 실행한 세션이면 4번을 EXPLAIN.md에 반영한다. 다른 세션이면 반영하지 않고 사용자에게 보여주기만 한다.
