# final: 제출 직전

1. **근거**: "설계"와 "결정"에 적힌 주장마다 근거(명령과 결과)를 "근거" 섹션에 연결한다. 근거가 없는 주장은 바로 확인하거나 `미검증: (확인 방법)`으로 표시한다. Tiger 위험의 대책이 실제로 반영됐는지도 확인한다. 버그를 찾으면 사용자에게 알리고 고칠지 묻는다.
2. **방어 노트**: "설명 질문" 5개에 각각 3~5줄로 답을 쓴다.
   - 설계 선택: 택한 방식 → 이유 → 대안과 차이 → 포기한 것
   - 검증 범위: 확인한 것(+명령) → 가정한 것 → 미구현
   - 동작과 예외: 정상 순서 → 예외별 동작 → 기존 데이터가 어떻게 되는지
   - 가장 약한 지점: 약점 → 무너지는 조건 → 실측 방법 → 개선
   - AI와 내린 결정: 계기 → 수용·수정·버림 → 근거
3. **퀴즈**: 질문을 한 번에 하나씩 낸다. 답은 먼저 보여주지 않는다. 사용자가 답하면 방어 노트와 비교해 빠진 것만 1~2줄로 짚는다.
4. **요약**: 사용자가 기억할 핵심을 질문당 한 줄, 총 5줄로 정리한다.
